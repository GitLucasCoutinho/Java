# 🗺️ Roadmap de Estudos em Java

Este roadmap organiza os temas do repositório em ordem de aprendizado.  
Use como **checklist**: marque ✅ conforme concluir cada projeto.

---

## 📂 Categoria 1 – Fundamentos do Java
- [X] Fundamentos → tipos primitivos, laços (`for`, `while`), operadores, controle de fluxo  
- [X] Tratamento de Exceções → `try/catch/finally`, exceções personalizadas  
- [X] Generics → classes e métodos genéricos  
- [ ] Enums → tipos enumerados  
- [ ] Anotações (Annotations) → metadados aplicados em classes e métodos  

---

## 📂 Categoria 2 – Estruturas de Dados
- [X] List Array HashSet Vector → exemplos de listas, vetores e conjuntos  
- [X] HashMapExample → uso de `HashMap` para chave/valor  
- [X] hashsetComparatorInterator → uso de `HashSet` com comparadores e iteradores  
- [X] Map → conceitos de `Map` (chave → valor)  
- [X] Interfaces e Arrays → arrays e interfaces relacionadas a coleções  
- [X] LinkedList → lista encadeada  
- [X] TreeSet / TreeMap → estruturas ordenadas  
- [ ] PriorityQueue → fila com prioridade  
- [ ] Deque / Stack → pilha e fila dupla  

---

## 📂 Categoria 3 – Utilitários e Recursos da Linguagem
- [X] WrappersExample → uso das classes wrapper (`Integer`, `Double`, etc.)  
- [X] MapExemploOptional → uso de `Optional` junto com `Map`  
- [X] Stream → processamento funcional de coleções  
- [X] Reduce → agregação de valores com `reduce`  
- [ ] Java I/O → leitura e escrita de arquivos  
- [ ] NIO (New I/O) → manipulação eficiente de arquivos e buffers  
- [ ] Date/Time API → trabalhar com datas e horários  
- [ ] Regex → busca e manipulação de strings  

---

## 📂 Categoria 4 – Programação Orientada a Objetos (POO)
- [ ] Herança e Polimorfismo → exemplos práticos  
- [X] Interfaces Funcionais → `Predicate`, `Function`, `Consumer`  
- [ ] Lambdas → expressões funcionais  
- [ ] Encapsulamento e Abstração → boas práticas de design  

---

## 📂 Categoria 5 – Conceitos Avançados
- [X] Threads e Concorrência → programação paralela e concorrente  
- [X] microserviços → arquitetura distribuída e serviços independentes  
- [ ] Design Patterns → Singleton, Factory, Strategy, Observer  
- [ ] Reflection API → inspecionar classes e objetos em tempo de execução  
- [ ] Serialização → salvar e recuperar objetos  
- [ ] JDBC → acesso a banco de dados relacional  
- [ ] Testes Unitários → JUnit, Mockito  

---

## 📂 Categoria 6 – Arquitetura e Frameworks
- [ ] Spring Boot → criação de aplicações modernas  
- [ ] Hibernate / JPA → persistência de dados  
- [ ] REST APIs → criação de serviços web  
- [ ] Microservices avançados → comunicação entre serviços, mensageria (Kafka, RabbitMQ)  

---

## 📂 Categoria 7 – Extras
- [ ] Segurança → autenticação, autorização, criptografia  
- [ ] Logging → SLF4J, Logback  
- [ ] Build Tools → Maven, Gradle  
- [X] Docker + Java → empacotando aplicações  
- [ ] Integração com Cloud → exemplos simples com AWS ou Azure
