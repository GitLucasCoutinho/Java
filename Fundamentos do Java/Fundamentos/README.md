# Fundamentos da Linguagem Java

Este projeto foi criado para praticar e demonstrar os **fundamentos da linguagem Java**, organizados em tópicos e métodos.  
O objetivo é ter um código limpo, modular e fácil de entender, servindo como guia de estudo.

---

## 🚀 Funcionalidades

O programa contempla os seguintes fundamentos:

- **Estrutura básica de um programa Java**
  - Classe principal e método `main`
- **Declaração de variáveis**
  - Tipos primitivos (`int`, `double`, `boolean`, `char`)
  - Strings
- **Constantes e atributos estáticos**
  - `static final`
- **Entrada e saída de dados**
  - `Scanner` para entrada
  - `System.out.print`, `println`, `printf` para saída
- **Estruturas condicionais**
  - `if/else`
- **Estruturas de repetição**
  - `for`, `while`, `for-each`
- **Arrays**
  - Declaração e acesso
- **Coleções**
  - `List` com `ArrayList`
- **Métodos**
  - Criação e chamada de métodos (`soma`)
- **Operadores lógicos**
  - `&&`, `||`, `|`

---

## 📂 Estrutura do Código

O código está organizado em **métodos separados** para cada tópico:

- `entradaDados()` → Entrada de dados com idade e emancipação  
- `estruturasCondicionais()` → Demonstração de `if/else`  
- `estruturasRepeticao()` → Laços `for` e `while`  
- `trabalharArrays()` → Uso de arrays  
- `trabalharColecoes()` → Uso de listas (`ArrayList`)  
- `usarMetodos()` → Exemplo de método auxiliar (`soma`)  
- `operadoresLogicos()` → Demonstração de operadores lógicos
