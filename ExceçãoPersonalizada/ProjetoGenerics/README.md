# 📦 Projeto Generics em Java

Este projeto demonstra o uso de **Generics** em Java, aplicados em:
- Classes genéricas (`Caixa`, `Par`)
- Métodos genéricos (`Util.imprimirArray`)
- Programa principal (`Main`) que mostra exemplos práticos

---

## 🛠️ Funcionalidades
- Criar uma **Caixa genérica** que pode armazenar qualquer tipo (`String`, `Integer`, etc.)
- Criar um **Par genérico** que associa chave e valor de tipos diferentes
- Usar um **método genérico** para imprimir arrays de qualquer tipo

---

## ▶️ Execução
Compile e execute a classe `Main.java`:

```bash
javac *.java
java Main

```

🎯 Objetivo
Este projeto foi criado para:
- Mostrar como Generics tornam o código reutilizável e seguro
- Demonstrar classes genéricas (Caixa, Par)
- Demonstrar métodos genéricos (Util.imprimirArray)
- Servir como base para projetos maiores que usam coleções e estruturas genéricas
- Ajudar desenvolvedores a entender e aplicar Generics em Java
- Fornecer exemplos práticos para aprendizado e referência futura
- Incentivar boas práticas de programação com tipos genéricos
- Facilitar a manutenção e evolução do código com menos erros de tipo
- Promover o uso de Generics em projetos Java
- Contribuir para a comunidade de desenvolvedores Java com exemplos claros e úteis
