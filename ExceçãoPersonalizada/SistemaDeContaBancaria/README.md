# 💳 Sistema de Conta Bancária (POO + Exceções)

Este projeto demonstra o uso de **Programação Orientada a Objetos (POO)** em Java, aliado ao **Tratamento de Exceções** (`try/catch/finally`) e a criação de uma **exceção personalizada**.  
O objetivo é simular operações básicas de uma conta bancária, como saque, e tratar erros de saldo insuficiente.

---


🛠️ Funcionalidades
- Criar uma conta bancária com titular e saldo inicial.
- Realizar saques válidos.
- Lançar exceção personalizada (`SaldoInsuficienteException`) em caso de saldo insuficiente.
- Usar `try/catch/finally` para garantir tratamento de erros e execução final.

---

🚀 Objetivo Didático
Este projeto foi criado para:
- Demonstrar POO com classes e objetos.
- Mostrar como criar e usar exceções personalizadas.
- Aplicar tratamento de erros com try/catch/finally.
