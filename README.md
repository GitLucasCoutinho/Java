# 📚 Projetos Didáticos em Java

Este repositório reúne diversos projetos didáticos em Java, organizados por **categorias** para facilitar o estudo e a consulta.  
Cada pasta contém exemplos práticos que ilustram conceitos fundamentais, estruturas de dados, recursos da linguagem e tópicos avançados.

---

## 📂 Categoria 1 – Fundamentos do Java
Projetos que tratam do **básico da linguagem**: tipos primitivos, estruturas de repetição e sintaxe inicial.

- **Fundamentos** → tipos primitivos, laços (`for`, `while`), operadores, controle de fluxo.

---

## 📂 Categoria 2 – Estruturas de Dados
Projetos que mostram como **organizar e armazenar informações** em coleções.

- **List Array HashSet Vector** → exemplos de listas, vetores e conjuntos.  
- **HashMapExample** → uso de `HashMap` para chave/valor.  
- **hashsetComparatorInterator** → uso de `HashSet` com comparadores e iteradores.  
- **Map** → conceitos de `Map` (chave → valor).  
- **Interfaces e Arrays** → arrays e interfaces relacionadas a coleções.

---

## 📂 Categoria 3 – Utilitários e Recursos da Linguagem
Projetos que exploram **classes auxiliares e recursos modernos** do Java.

- **WrappersExample** → uso das classes wrapper (`Integer`, `Double`, etc.).  
- **MapExemploOptional** → uso de `Optional` junto com `Map`.  
- **Stream** → processamento funcional de coleções com `Stream`.  
- **Reduce** → agregação de valores com `reduce`.

---

## 📂 Categoria 4 – Conceitos Avançados
Projetos que vão além do básico, explorando **paralelismo e arquitetura**.

- **Threads e Concorrência** → programação paralela e concorrente.  
- **microserviços** → conceitos de arquitetura distribuída e serviços independentes.

---

## 🚀 Objetivo
Este repositório serve como **material de estudo** e prática para quem deseja aprender Java de forma progressiva:
1. Comece pelos **Fundamentos**.  
2. Avance para **Estruturas de Dados**.  
3. Explore os **Utilitários e Recursos modernos**.  
4. Por fim, mergulhe nos **Conceitos Avançados**.

---

## 📝 Observação
Cada projeto é **independente** e pode ser executado separadamente.  
Eles foram criados com fins **didáticos**, para reforçar conceitos e boas práticas em Java.
