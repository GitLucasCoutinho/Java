# 📚 Projetos Didáticos em Java

Este repositório reúne diversos projetos didáticos em Java, organizados por **categorias** para facilitar o estudo e a consulta.  
Cada pasta contém exemplos práticos que ilustram conceitos fundamentais, estruturas de dados, recursos da linguagem e tópicos avançados.

---

## 📂 Categoria 1 – Fundamentos do Java
Projetos que tratam do **básico da linguagem**: tipos primitivos, estruturas de repetição e sintaxe inicial.

- **Fundamentos** → tipos primitivos, laços (`for`, `while`), operadores, controle de fluxo.
- **Tratamento de Exceções** → uso de `try/catch/finally`, exceções personalizadas.
- **Generics** → exemplos de classes e métodos genéricos.
- **Enums** → uso de tipos enumerados para constantes.
- **Anotações (Annotations)** → metadados aplicados em classes e métodos.

---

## 📂 Categoria 2 – Estruturas de Dados
Projetos que mostram como **organizar e armazenar informações** em coleções.

- **List Array HashSet Vector** → exemplos de listas, vetores e conjuntos.  
- **HashMapExample** → uso de `HashMap` para chave/valor.  
- **hashsetComparatorInterator** → uso de `HashSet` com comparadores e iteradores.  
- **Map** → conceitos de `Map` (chave → valor).  
- **Interfaces e Arrays** → arrays e interfaces relacionadas a coleções.  
- **LinkedList** → lista encadeada.  
- **TreeSet / TreeMap** → estruturas ordenadas.  
- **PriorityQueue** → fila com prioridade.  
- **Deque / Stack** → pilha e fila dupla.

---

## 📂 Categoria 3 – Utilitários e Recursos da Linguagem
Projetos que exploram **classes auxiliares e recursos modernos** do Java.

- **WrappersExample** → uso das classes wrapper (`Integer`, `Double`, etc.).  
- **MapExemploOptional** → uso de `Optional` junto com `Map`.  
- **Stream** → processamento funcional de coleções com `Stream`.  
- **Reduce** → agregação de valores com `reduce`.  
- **Java I/O (Input/Output)** → leitura e escrita de arquivos.  
- **NIO (New I/O)** → manipulação eficiente de arquivos e buffers.  
- **Date/Time API (java.time)** → trabalhar com datas e horários.  
- **Regex (Expressões Regulares)** → busca e manipulação de strings.

---

## 📂 Categoria 4 – Programação Orientada a Objetos (POO)
Projetos que reforçam os pilares da **orientação a objetos**.

- **Herança e Polimorfismo** → exemplos práticos.  
- **Interfaces Funcionais** → `Predicate`, `Function`, `Consumer`.  
- **Lambdas** → expressões funcionais.  
- **Encapsulamento e Abstração** → boas práticas de design.

---

## 📂 Categoria 5 – Conceitos Avançados
Projetos que vão além do básico, explorando **paralelismo, arquitetura e boas práticas**.

- **Threads e Concorrência** → programação paralela e concorrente.  
- **microserviços** → conceitos de arquitetura distribuída e serviços independentes.  
- **Design Patterns (Padrões de Projeto)** → Singleton, Factory, Strategy, Observer.  
- **Reflection API** → inspecionar classes e objetos em tempo de execução.  
- **Serialização** → salvar e recuperar objetos.  
- **JDBC** → acesso a banco de dados relacional.  
- **Testes Unitários** → JUnit, Mockito.

---

## 📂 Categoria 6 – Arquitetura e Frameworks
Projetos que mostram como aplicar Java em **cenários reais de mercado**.

- **Spring Boot** → criação de aplicações modernas.  
- **Hibernate / JPA** → persistência de dados.  
- **REST APIs** → criação de serviços web.  
- **Microservices avançados** → comunicação entre serviços, mensageria (Kafka, RabbitMQ).

---

## 📂 Categoria 7 – Extras
Projetos que complementam o aprendizado com **ferramentas e práticas importantes**.

- **Segurança** → autenticação, autorização, criptografia.  
- **Logging** → SLF4J, Logback.  
- **Build Tools** → Maven, Gradle.  
- **Docker + Java** → empacotando aplicações.  
- **Integração com Cloud** → exemplos simples com AWS ou Azure.

---

## 🚀 Objetivo
Este repositório serve como **material de estudo** e prática para quem deseja aprender Java de forma progressiva:
1. Comece pelos **Fundamentos**.  
2. Avance para **Estruturas de Dados**.  
3. Explore os **Utilitários e Recursos modernos**.  
4. Reforce a **POO**.  
5. Mergulhe nos **Conceitos Avançados**.  
6. Aprenda **Arquitetura e Frameworks**.  
7. Finalize com os **Extras** para se aproximar do mercado.

---

## 📝 Observação
Cada projeto é **independente** e pode ser executado separadamente.  
Eles foram criados com fins **didáticos**, para reforçar conceitos e boas práticas em Java.
