# **App Name**: TaskFlow

## Core Features:

- Task Creation: Allow users to add new tasks to their todo list with titles and descriptions.
- Task Listing: Display the current todo list items, grouped by pending vs done.
- Task Editing: Enable users to edit existing tasks to modify their titles or descriptions.
- Task Deletion: Provide the ability to delete tasks from the todo list.
- Task Completion: Allow users to mark tasks as complete and move them to a 'completed' state.
- Smart Suggestions: AI powered task name suggestions tool based on user habits and task category.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) to create a sense of calm and focus.
- Background color: Very light blue (#E0F2F7), near-white, for a clean and spacious feel.
- Accent color: Soft lavender (#E6E6FA) to highlight interactive elements and important actions.
- Body and headline font: 'PT Sans', a humanist sans-serif font known for its readability and modern feel, will be used.
- Simple, outline-style icons to represent task categories and actions. Use a consistent stroke weight and a size that is easily recognizable.
- Use a card-based layout for individual tasks, making it easy to scan and manage tasks on both desktop and mobile devices. The layout should be clean and intuitive.
- Use subtle animations to provide feedback on user actions, such as marking a task as complete or deleting it. These animations should be smooth and not distracting.
